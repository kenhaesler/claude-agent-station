## Invariants we verified

- `audit_rows == decisions` at every level → one `agent_events` row per tool call.
- ALWAYS_DENY (push to main, force push) blocks at **every** level including `auto`.
- Destructive bash (`rm -rf`, `git reset --hard`) is denied at `manual`/`assisted`
  and allowed at `auto`, matching the ADR-0001 policy matrix.
- Read-only tools (`Read`, `Glob`, `Grep`) and edit tools (`Write`, `Edit`) are
  allowed at `assisted` and `auto`; edits are denied at `manual`.
- Per-decision overhead is in the low double-digit microseconds — the policy +
  sqlite write do not add meaningful latency to a tool call.

## What this does NOT cover

- Turn counts, wall-clock duration, and Anthropic API cost for a real run —
  those require the SDK to actually drive a teammate against a repo.
- Subagent spawn accounting (the `Agent`/`Task` tool path) — modelled here as
  allowed, but the real run will show how often the lead actually fans out.
- Interactive cases that the Phase 2 permission tray will surface.
